NON-COMMERCIAL · PLANNING & RESEARCH STAGE

01 / About the project

Made for your own
collection.

NINA CINEMA is a personal, non-commercial web application concept designed with iPhone and modern browsers in mind. The proposed Progressive Web App (PWA) will help organize information about movies, television series, short-form dramas, and AI-generated dramas.

The full application is still being researched and planned. It has not launched.

02 / Planned experience

A library, on your terms.

01Discover titles

Explore publicly available information about films, series, and short-form dramas.

02Save favorites

Build a personal watchlist and organize titles into a private collection.

03Track your journey

Keep personal viewing progress and season or episode notes where supported.

03 / Metadata research

Respecting the source.

NINA CINEMA is evaluating lawful, publicly accessible metadata providers, including The Movie Database (TMDB), for titles, descriptions, genres, posters, seasons, and episodes.

TMDB API integration has not been implemented. No API access or integration approval is being claimed.

No TMDB API data is currently displayed on this page. Any future integration will follow the applicable API terms, attribution, and branding requirements.

NINA CINEMA is an independent project and is not affiliated with or endorsed by TMDB.

04 / Project status & content policy

Still in the making.

Status: Planning and technical research. The application is not publicly available or launched.

Purpose: Personal media organization and metadata discovery only.

Content: This project does not host, stream, distribute, or offer downloads of video content.

Scope: This page is a public project introduction, not the application itself.
